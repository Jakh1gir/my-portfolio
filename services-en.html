Websites and software applications

I am interested in clear, responsive websites and web tools that help people complete real tasks. A portfolio or service website needs useful content, readable sections, working links and simple ways to get in touch.

A web application may include forms, data retrieval, filtering, calculations or API connections. Before implementation, the expected user flow, information model and technical constraints need to be defined.

Python, APIs and automation

Python is useful for repetitive work involving spreadsheets, CSV data, documents, reports and scheduled operations. Reliability comes from validating input, handling errors and keeping records of what happened.

APIs can connect permitted sources to applications or Telegram bots. Each integration needs a review of authentication, rate limits, access rights and data handling rather than assuming that every service can be connected.

Telegram bots, Android and local AI

Telegram bots can provide commands, notifications and controlled publishing workflows. Android is another area of my work: J1Calc is a mobile calculator currently described as a beta product.

Local_DB Universal focuses on local records and documents; Visual Pack explores OCR for PDFs and images; DB AI Core develops document-based local AI assistance. The software is at different stages and not every planned integration is finished.

Working together

I am based in Tashkent, Uzbekistan. To discuss a task, describe who will use the product, what information it will process, and what outcome matters most.

A practical first step is usually a small, testable prototype. Features, timelines, costs and any remote collaboration arrangements are agreed only after reviewing the requirements.

These are relevant development directions, not a claim that every possible product is already available or completed.
