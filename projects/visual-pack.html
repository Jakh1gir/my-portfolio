Visual Pack — текст из изображений и PDF

Visual Pack 1.3.3 — отдельный модуль обработки PDF, изображений и DXF с распознаванием текста и поиском обозначений KKS. Исходники обновлены; кандидат установщика Windows пока не прошёл подтверждённую сквозную приёмку.

Зачем нужен Visual Pack

Модуль объединяет векторный текст PDF, OCR на изображениях, DXF-текст и геометрию, локальный индекс и поиск KKS с координатами на листе. Он работает как отдельный worker по версии протокола v3.

Один из практических сценариев — распознать текст, найти нужные фрагменты и подготовить их к дальнейшей работе в локальной программе. Результат OCR зависит от качества исходного изображения.

Что находится в развитии

В main доступен код 1.3.3, однако Windows Setup 1.3.3 обозначен кандидатом. Требуются отдельная сборка и сквозное тестирование совместимости с Core и Local_DB. 5 декабря 2026 года остаётся плановым ориентиром, а не подтверждением выпуска.

В числе дальнейших задач — повышение качества распознавания, поддержка разных вариантов PDF и изображений, поиск по извлечённым фрагментам и проверка работы на реальных документах.

Связь с локальными AI-инструментами

Visual Pack устанавливается отдельно и взаимодействует с Core через worker API и протокол v3. Исходные документы остаются под управлением Local_DB, а корректность распознанных схем должна проверяться по оригиналам.

Такой процесс требует контроля исходных файлов и проверки найденного текста. Ошибки распознавания могут повлиять на последующие AI-ответы, поэтому работа с источниками остаётся важной частью архитектуры.

Статус: исходники Visual Pack 1.3.3; Windows Setup и трёхкомпонентная интеграция не прошли подтверждённую приёмку.
